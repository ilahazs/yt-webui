# frontend

React 19 frontend for yt-dlp Web UI, built with TanStack Router, Zustand, shadcn/ui, and Tailwind CSS v4.

## Stack

| Tool | Purpose |
|---|---|
| [React 19](https://react.dev) | UI framework |
| [TanStack Router](https://tanstack.com/router) | File-based type-safe routing |
| [Zustand](https://zustand-demo.pmnd.rs) | Lightweight state management |
| [shadcn/ui](https://ui.shadcn.com) | Accessible UI components (new-york style) |
| [Tailwind CSS v4](https://tailwindcss.com) | Utility-first styling |
| [Vite](https://vitejs.dev) | Dev server and bundler |
| [pnpm](https://pnpm.io) | Package manager |

## Project Structure

```txt
src/
├── main.tsx              # React root + router setup
├── index.css             # Design tokens, shadcn/ui vars, Tailwind v4
├── routeTree.gen.ts      # Auto-generated by TanStack Router (do not edit)
├── routes/
│   ├── __root.tsx        # Root layout (nav, shell)
│   └── index.tsx         # Home / probe page
├── components/
│   ├── ui/               # shadcn/ui components
│   └── FeatureCard.tsx   # Feature highlight card
├── hooks/
│   ├── useProbe.ts       # URL probe hook
│   └── useJobEvents.ts   # SSE subscription hook
├── store/
│   └── useJobStore.ts    # Zustand store for job state + SSE management
└── lib/
    ├── utils.ts          # cn() class merge utility
    ├── api.ts            # Type-safe API client
    └── types.ts          # Shared TypeScript types
```

## Developing

```sh
pnpm install
pnpm run dev
```

The development server starts at `http://localhost:5173`. API requests to `/api/*` are proxied to the Go backend at `http://localhost:8080`.

## Building

```sh
pnpm run build
```

Preview the production build:

```sh
pnpm run preview
```

## Adding shadcn/ui Components

```sh
npx shadcn add <component-name>
```

This requires the `components.json` configuration already present in this directory.

## Adding Routes

Create a file under `src/routes/`. TanStack Router's Vite plugin automatically detects new route files and regenerates `routeTree.gen.ts`.

- `src/routes/index.tsx` → `/`
- `src/routes/jobs/index.tsx` → `/jobs`
- `src/routes/jobs/$jobId.tsx` → `/jobs/:jobId`
